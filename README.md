# LankaReads
A web application for searching and discovering books from Sri Lankan bookstores.
## Languages used
- Python
- Flask
- SQLite
- BeautifulSoup
- HTML/CSS
- Bootstrap

## Features
- Search for books
- Display book information
- Scrape book data from multiple Sri Lankan bookstores
- Responsive web interface

## What I Learned
- Flask application structure
- Web scraping
- Working with SQLite databases
- REST-style application design
